Privacy policy

Last updated: November 25, 2026

This application is a personal Google sign-in configuration used with rclone. Its owner is its only intended user.

  • Data accessed: Google Drive files and file information, used only to list, read, upload, change and delete files at the user's request.
  • Storage: file copies, cached data and the sign-in token stay on the user's own computer. There is no server that receives them.
  • Sharing: data is not sold or shared, and is not used for advertising or analytics. Files travel only between the user's computer and Google.
  • Removal: access can be revoked at any time at myaccount.google.com/connections.
